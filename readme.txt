Предупреждения 18+, ручной публичный анонс и серверная выдача полного материала после подтверждения.

== Description ==
Библиотека шаблонов, один шаблон на статью/страницу, подписанные подтверждения, обычная форма без JavaScript, публичные REST/RSS-представления и правила для ограниченных медиа.

Подтверждение является заявлением посетителя о возрасте. Внешние провайдеры не подключены. Прямые файлы не защищаются авторизацией. Кеш/CDN нужно настроить отдельно. Подробности и ограничения — в README.md.

== Installation ==
1. Загрузите каталог avela в wp-content/plugins.
2. Активируйте Avela.
3. Откройте «Предупреждения» и выберите предупреждение в редакторе нужной статьи.
4. Отключите общий HTML-кеш и проверьте robots.txt по инструкции README.md.
